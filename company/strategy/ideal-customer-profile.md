# Ideal Customer Profile (ICP)

関連: [positioning.md](positioning.md) / [../sales/sales-playbook.md](../sales/sales-playbook.md)

## 1. 一次ターゲット: 在米日系企業の現地法人

| 属性 | 条件 |
|---|---|
| 業種 | 製造 (自動車部品・機械・化学)、商社、物流、食品 |
| 規模 | 現地従業員 50〜500名 / バックオフィス 3〜15名 |
| 地域 | NY/NJ首都圏 → 中西部 (自動車系) → 全米 |
| システム | SAP (ECC or S/4HANA、本社主導で導入済み)、Excel多用、Zendesk/メールでサポート運用 |
| 構造的な痛み | 本社標準のSAPは変えられない / 現地ITは1〜2名か外注 / 手作業が経理・営業管理に滞留 / 日本本社への月次報告が重い |

**なぜ勝てるか**: 日英バイリンガル + 日系企業の意思決定構造 (本社稟議・現地裁量の範囲) を
理解した上で、「本社を変えずに現地の周辺を自動化する」提案ができる。

## 3. バイヤーペルソナ

| ペルソナ | 役職 | 痛み | 刺さる言葉 |
|---|---|---|---|
| 経済的決裁者 | CFO / Controller / 管理部長 | 監査対応・締めの遅さ・残業コスト・ミスのリスク | 回収期間、エラー削減、監査証跡 |
| 実務チャンピオン | 経理マネージャ / CSマネージャ | 自チームの手作業・離職・属人化 | 「あの業務が消える」具体性 |
| 技術ゲートキーパー | ITマネージャ / 情シス | セキュリティ・本社標準との整合・保守負担 | 最小権限、ログ、ロールバック、本社標準を壊さない |
| (日系のみ) 本社側 | 日本本社の経営企画・IT | 現地の可視性、DX実績報告 | 日本語での報告資料、本社標準準拠 |

## 4. 理想的な最初の10社の条件

1. 月20時間以上の特定可能な手作業がある (請求書入力・レポート作成・転記)
2. SAPまたはZendeskを使っている (既存テンプレート資産が刺さる)
3. 決裁者に2ステップ以内で届く (紹介・既存人脈・業界団体)
4. データアクセスを許可できる (検証環境 or 本番の限定権限)
5. 成功したら次の業務・他部門への展開余地がある

## 5. ディスクオリファイ条件 (受けない案件)

| 兆候 | 理由 |
|---|---|
| 「とりあえずAIで何かやりたい」(対象業務が特定できない) | PoC止まりリスク。Assessmentで業務特定から始めるなら可 |
| 常駐・人月契約・派遣的な体制要求 | 人月依存を減らす方針に反する (§business-plan 8) |
| ERP自体の入れ替え・大規模SI | 14日納品不能。パートナー紹介に回す |
| データアクセスを一切許可できない | 動くものが作れない |
| 予算承認者が特定できない / $3,000のAssessmentすら稟議が通らない | 支払い意思の欠如 |
| 要求が違法・グレー (スクレイピングによる規約違反等) | 信頼性が資産のため |

## 6. リードソース (見込み100社リストの作り方)

1. ジェトロ/日系商工会議所の会員名簿 (NY/NJ/中西部の日系現地法人)
2. 既存人脈: 前職・業界の経理/IT担当者 → 紹介依頼
3. LinkedIn: 「Controller + SAP + (日系企業名)」で検索
4. Zendeskコミュニティ / SAPユーザーグループ (ASUG) のイベント
5. 日系ビジネスメディア・ニュースレターへの寄稿 (自動化事例)
