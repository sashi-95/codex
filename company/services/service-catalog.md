# Service Catalog — 提供サービス定義

関連: [pricing.md](pricing.md) / [../delivery/delivery-methodology.md](../delivery/delivery-methodology.md)

## サービス体系 (顧客の旅に沿って)

```
① Automation Assessment ($3,000 / 5営業日)
      ↓ 対象業務とROIが確定
② AI Automation Sprint ($15,000 / 7-14営業日)
   または Enterprise Sprint ($25,000 / 10-14営業日)
      ↓ 本番稼働
③ Monthly Support ($3,000-10,000/月)
      ↓ 効果実測 → 次の業務へ
④ 追加Sprint / 追加開発 (リピート)
```

## ① Automation Assessment — $3,000 (固定・5営業日)

| 項目 | 内容 |
|---|---|
| 目的 | 自動化対象業務の選定と投資判断材料の提供 |
| 実施内容 | 業務ヒアリング (2-3セッション) / 現状業務の構造化 / 自動化候補の洗い出しと優先順位付け / ROI試算 / 技術構成案 / 実行計画 |
| 成果物 | Assessment Report (現状マップ、候補一覧、ROI試算、推奨Sprint計画、概算見積) |
| 顧客の負担 | 担当者ヒアリング各60分×2-3回、サンプルデータ提供 |
| 位置づけ | 有償の入口商品。**Sprint受注時は$3,000をSprint費用に充当** (実質無料化でクロージング圧力に) |

## ② AI Automation Sprint — $15,000 (固定・7〜14営業日)

| 項目 | 内容 |
|---|---|
| 目的 | 選定した1業務の自動化を本番環境で稼働させる |
| スコープ | 1業務プロセス / 連携システム2つまで / 承認フロー1つまで |
| 成果物 | 動く自動化 (本番デプロイ) / 運用runbook / 引き継ぎ資料 / ロールバック手順 / UAT記録 / 効果測定の仕組み |
| 対象業務例 | SAPレポート自動抽出 / Excel加工 / 定期メール配信 / Zendesk問い合わせ自動分類 / FAQ自動回答 / チケット起点のワークフロー実行 / 添付ファイル処理 / 証跡保存 / 月次業務 / 社内ナレッジ検索 / Power BIレポート生成 / 定型メール・報告書作成 |
| 含まれないもの | ERP設定変更 / 新規ライセンス費用 / 3システム以上の統合 (→Enterprise) |

## ③ Enterprise Sprint — $25,000 (固定・10〜14営業日)

Sprintとの差分 (以下のいずれかに該当する案件):

- SAP等の基幹システムへの**書き込み**を含む (転記・起票)
- HITL承認フロー・監査ログ・SoD等のコンプライアンス要件
- 3システム以上の統合、または本社ITとの調整が必要
- 日英両言語でのドキュメント納品

追加成果物: セキュリティ設計書 / 監査ログ仕様 / 承認フロー定義 / 障害時の手動代替手順。

## ④ Monthly Support — $3,000〜10,000/月 (前払い)

| ティア | 月額 | 内容 |
|---|---|---|
| Basic | $3,000 | 稼働監視・障害対応 (営業時間内) / 月次ヘルスレポート / 軽微修正 4時間分 |
| Standard | $6,000 | Basic + 改善開発 10時間分 / 四半期の業務レビュー / 優先対応 |
| Premium | $10,000 | Standard + 改善開発 20時間分 / 新規自動化候補の継続提案 / 本社向け日本語報告書 |

原則: 全Sprint納品時にBasic以上を提案する (納品物の性質上、保守なし運用は顧客リスク)。
1人運営のキャパ上限: 保守契約は当面10社まで。超過見込みで値上げまたは外部委託。

## ⑤ 追加開発

- 原則 **固定価格** (スコープを切ってミニSprint化: $5,000〜)
- 例外的に時間単価 $250/h (調査・障害解析など見積不能な作業のみ)

## 納品を加速する社内テンプレート資産 (既存)

| 資産 (本リポジトリ) | 流用先 |
|---|---|
| `src/support-agent/` Zendesk自律エージェント | 問い合わせ分類 / FAQ自動回答 / チケットワークフロー |
| `python/backoffice_agent/` 請求書処理ランタイム | SAP転記 / 添付処理 / 承認フロー / 突合 |
| `python/` レポートカタログ+ルーティン | レポート自動抽出 / 月次業務 / 定期配信 |
| `sapgui-vbs/` SAP GUI自動化 + PAD | SAP GUI入力 / SAPレポート抽出 / 証跡保存 |
| `src/agent-os/` エージェント基盤 | マルチエージェント案件の骨格 |

新規案件で作った汎用部品は匿名化してこの資産群に還流する (再利用可能なIPの蓄積)。
